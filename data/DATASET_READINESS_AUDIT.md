# IVA dataset readiness audit — 2026-11-17

## Scope and decision

This is a first-pass inspection of the 16 entries that were marked `candidate`
before this audit. Repository cards, file layouts and bounded raw-file samples
were inspected where the Hub exposed them. Some Parquet and compressed sources
could not be sampled in this pass.

**No dataset is approved for training.** The registry remains
`training_enabled: false`. A candidate is only eligible for quarantine and
further review. Declared Hub licenses are publisher metadata, not independent
proof of rights for every upstream record or edition. Hugging Face documents
dataset cards as the place for source, license, language and usage context:
https://huggingface.co/docs/hub/en/datasets-cards

## Important corrections

1. The previous registry contained 16 candidates. One source,
   `s85io/math-logic-ru`, is now `hold` because a concrete invalid proof was
   observed. The registry therefore now has 15 candidates and 14 holds.
2. `T-math` remains evaluation-only. Its presence in the quarantine selector
   does not grant permission to use it for training.
3. `MathInstruct` cannot be treated as uniformly MIT-licensed: its own card
   identifies a non-listed upstream source and a CC BY-NC 4.0 subset. Row-level
   source filtering and rights review are mandatory.
4. Sample observations are not full-corpus statistics. No raw samples are
   copied into this report.

## Repeatable bounded sample audit

Run **Actions → IVA dataset candidate sample audit (quarantine only)** and
select a registry ID. The workflow streams at most 500 rows and writes only
aggregate diagnostics (schema, language share, duplicate/boilerplate signals
and possible contact-data counts). It never stores raw sample text, changes
registry status, edits a training manifest or approves a dataset.

Local equivalent:

```bash
pip install "datasets>=3.0,<5.0"
python scripts/audit_hf_dataset_candidate.py \
  --dataset-id d0rj_math_dataset_ru --max-rows 250
```

Use `--config` and `--split` to override defaults. A failed preview is recorded
as an audit failure, not as a clean bill of health.

## Final gate before training

Every source must pass all of the following independently:

- exact source revision/hash recorded;
- rights and upstream licenses reviewed, including attribution/share-alike terms;
- privacy screening and human spot-check completed;
- schema, language and split boundaries verified;
- exact and near-duplicate analysis completed;
- domain-specific factual/math/physics/proof validation completed;
- train/validation/test leakage checked;
- human maintainer records the decision and exact allowed scope.

Until then, every source remains quarantined and `training_enabled` remains
`false`.
