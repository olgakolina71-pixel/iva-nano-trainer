# IVA Nano — аудит кандидатов датасетов (2026-11-19)

## Решение
Ни один внешний кандидат не одобрен для обучения. Объявленная на Hugging Face лицензия CC0 — важный сигнал, но не заменяет проверку происхождения каждого фрагмента, персональных данных и качества.

## 1. Imperius/ru-classic
- Hub указывает CC0-1.0; корпус описан как русская классическая литература из lib.ru.
- Структура: около 6,9 млн строк train, одна колонка text.
- Первые строки предпросмотра: имя автора, отдельные строки с двоеточиями и пустые фрагменты. Требуется проверка сегментации.
- Назначение: возможный отдельный кандидат для языкового предобучения, не диалоговый SFT.
- До использования: проверить целостность записей, OCR, редакторские материалы и происхождение каждого текста.
- Решение: HOLD; не включать в SFT.

Источник: https://huggingface.co/datasets/Imperius/ru-classic

## 2. nyuuzyou/edutexts
- Hub указывает CC0-1.0; заявлены около 1,38 млн презентаций и документов на русском, украинском и английском.
- В предпросмотре презентации обнаружены имя ученицы и обозначение класса («10 Б»).
- Нужна проверка персональных данных, учебных учреждений, авторства и прав на исходные документы.
- Одного удаления имени недостаточно для подтверждения правомерности использования всего содержимого.
- Решение: HOLD; фильтрация персональных данных и проверка происхождения/прав.

Источник: https://huggingface.co/datasets/nyuuzyou/edutexts

## 3. SonexaAI/Small-Life-Dataset-ru-eng
- Hub и README заявляют CC0-1.0; файл train.jsonl присутствует.
- Предпросмотр показывает точные повторы вопросов и ответов, короткие слабые ответы, языковые ошибки и противоречивую идентичность ассистента (например, «Меня зовут Иван»).
- README содержит шаблонные поля автора и citation URL с [username].
- Dataset Viewer не смог загрузить конфигурацию; статистика README не подтверждена независимо.
- Решение: HOLD; нужен полный анализ JSONL, дедупликация, языковая/качественная фильтрация и подтверждение происхождения.

Источник: https://huggingface.co/datasets/SonexaAI/Small-Life-Dataset-ru-eng

## 4. Оригинальные диалоги IVA
- Исходный файл из 191 пары пока не изменён.
- Новые примеры следует добавлять отдельной версией после проверки уникальности вопросов, качества ответов и формата.
- Личные переписки и API-ключи не следует копировать в датасет без отдельной проверки и обезличивания.
- Статус прав и финального редакторского одобрения остаётся pending. Обучение не включено.

## Ограничения
Это выборочная первичная проверка карточек, структуры и предпросмотра записей, а не юридическое заключение и не полный построчный аудит всех файлов. Ни один внешний корпус не получил статус approved.
