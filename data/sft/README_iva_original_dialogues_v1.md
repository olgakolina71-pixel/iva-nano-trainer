# IVA Nano — оригинальный русский диалоговый датасет v1

- Количество пар: 191
- Формат: UTF-8, пары `### Пользователь:` / `### IVA:`
- Назначение: начальное supervised fine-tuning (SFT) для русскоязычного общения.
- Происхождение: примеры написаны специально для проекта IVA Nano; внешние диалоги и персональные данные не использовались.
- Статус: черновик для проверки человеком, НЕ одобрен автоматически для обучения.
- Перед запуском обучения проверьте качество, повторы, формат, лицензионные условия проекта и корректность каждого ответа.

Датасет намеренно содержит разнообразные короткие и средние ответы, уточняющие вопросы, признание неопределённости и базовые правила безопасной работы с ключами и файлами.

## Проверка формата

Каждый пример должен содержать непустой запрос пользователя и непустой ответ IVA. Разделитель между примерами — пустая строка.
